# Wildforge

Wildforge is an original browser-based voxel survival game built with Three.js. The project begins with a familiar block-survival baseline, then grows into its own visual identity, world, systems, and progression.

## Run locally

On Windows, double-click `Start-Wildforge.bat`. Use `Stop-Wildforge.bat` to stop only the verified Wildforge server on port 7000.

```bash
npm install
npm run dev
```

Open the URL printed by Vite, click **Enter World**, and use the controls shown on the title screen.

For a boosted, save-isolated testing world, open `http://localhost:7000/?seed=wildforge&playtest=1`. See the [complete playtest handbook](docs/PLAYTEST_GUIDE.md) for controls, ordered smoke tests, system checklists, and bug-report guidance.

For restart instructions and the exact current continuation state, see [the project handoff](docs/HANDOFF.md).
